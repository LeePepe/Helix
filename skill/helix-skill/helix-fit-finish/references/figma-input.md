# Figma Input

Provide Figma context in either of these ways:

- Figma Desktop selection (no URL): select the target node in Figma Desktop, then run the Helix workflow.
- Figma URL: provide a full Figma URL with node-id.

Examples:

- https://www.figma.com/file/ABC123?node-id=123:456
- https://www.figma.com/design/ABC123?node-id=123:456

Notes:

- Figma MCP is required for both Desktop selection and URL-based access.
- If the URL is missing node-id, request the user to provide the exact node.
