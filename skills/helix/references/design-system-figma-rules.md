# Design System Init: Figma Rules

## Goal

Fetch Figma design system rules to seed the project design system guide.

## Actions

1. Call the Figma MCP tool to generate design rules:
   - `mcp_figma-desktop_create_design_system_rules`
   - or `mcp_figma_create_design_system_rules`
2. Capture the returned prompt/rules output for use in the final guide.

## Output

- Figma design system rules and token definitions
