# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project Overview

Helix is a **Claude Code skill pack** (packaged as a plugin) for design-to-code workflows:
- **`helix`** — router skill; dispatches to fit-finish, gen-code, or design-system-init
- **`helix-fit-finish`** — compare a Figma node vs code, produce a prioritized mismatch report
- **`helix-gen-code`** — generate production-ready code from Figma using the design system
- **`helix-design-system-init`** — generate `.github/design-system-guide.md`

## Structure

```
.claude-plugin/marketplace.json   # marketplace listing the helix plugin
.claude-plugin/plugin.json        # plugin manifest
skills/
├── helix/                        # router; references/ holds all shared spec docs
├── helix-fit-finish/             # parallel Phase 1 orchestrator
├── helix-gen-code/               # sequential pipeline orchestrator
└── helix-design-system-init/     # guide generator
agents/                           # six subagents (helix-*.md) + openai.yaml
```

Sub-skills reference shared docs via `../helix/references/...`, so the four skill dirs MUST stay siblings. Each agent file needs `name:` + `description:` frontmatter.

## Conventions

- **Design domains are never hardcoded** — discovered dynamically from `.github/design-system-guide.md`.
- Figma MCP server required: `http://127.0.0.1:3845/mcp` (Desktop) or `https://mcp.figma.com/mcp` (remote).
- Design system guide is the central data source: generated by `helix-design-system-init`, read by all others.

## Validate plugin

```bash
claude plugin marketplace add ./          # should list "helix"
claude plugin install helix@helix         # skills + agents bundle
```
